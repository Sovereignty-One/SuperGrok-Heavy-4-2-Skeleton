Sovereign Mentor - Voice Companion

This is a minimal SwiftUI project for App Maker Pro.

To use in App Maker Pro:
1. Clone this repo
2. Open the SovereignMentor folder
3. If it complains about missing .xcodeproj, create a new blank project in App Maker Pro and paste the ContentView.swift content.

For real Xcode: Open the folder in Xcode on Mac to auto-generate the project.
